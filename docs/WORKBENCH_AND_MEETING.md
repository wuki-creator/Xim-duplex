# 伴点 · 工作台与会议空间

v0.8.0 在原有对话舱外增加两个独立页面。主对话面板只显示一个「实时语音」开关；麦克风诊断继续供内部处理。没有及时接话时仍可保留已确认的语句，并通过基础语音接续。

## 物理工作台

打开 `/workbench.html`。用鼠标拖动可转动视角，滚轮缩放，点击物体选择。可添加方块、球与圆柱；输入三轴坐标移动，或者让虚拟机械臂抓取、放置和释放。开启模拟后使用 Cannon ES 计算重力、刚体接触与碰撞。场景里的 Y 轴朝上。

语音或文字示例：

- 「添加一个红色方块，叫小砖。」
- 「把小砖移到 X 2.4、Y 1、Z 0.8。」
- 「让机械臂抓起小砖。」
- 「把它放到 X 2.2、Y 1、Z -1。」
- 「计算当前场景的下落结果。」
- 「下载 Blender 导入文件。」
- 「生成一张放着暖色灯的机器人实验台图片。」

语音使用基础转写，DeepSeek 只返回预设指令。可下载 JSON、含几何和材质的 `.gltf`、用于 Blender 导入的 Python 脚本和完整计算报告。`.gltf` 为当前场景快照，机械臂没有 Blender 可编辑骨骼；脚本生成地面和物体，不操作原工程文件。图像使用模思的 [文生图 API](https://platform.moss.cn/docs/reference/images-generations/)，明确确认才发起一张图片请求。

### 计算范围

同一求解器可在服务器或本机 Python 上运行，页面标明实际计算位置。服务器当前通过 SSH 加密通道访问；远端计算 HTTP 进程只监听回环地址。`private/workbench.json` 可设置 `{"compute_url":"http://127.0.0.1:18793"}`，也可设置 `XIM_COMPUTE_URL`。外部计算地址只能指向本机回环接口。连接失败时使用本机求解器。

- `arm`：在固定三关节尺寸下求速度平滑的 37 点位置与逆运动学解。两轴坐标以实际模型为准；不可达目标拒绝执行。它不计算机械臂对障碍物的绕行或真实硬件极限。
- `physics`：计算忽略空气阻力、物体间遮挡时的自由落体时间及撞地速度。浏览器的接触与碰撞模拟独立运行，表格明确标为下落估算。

重启服务器后可在约定的独立目录运行 `python3 compute_world.py`，默认回环端口 18794；本机可使用 `scripts/ssh_asr_tunnel.py` 的 `--local-port 18793 --remote-port 18794` 建立转发。应用不会执行用户或模型给的任意代码，也不连接实体机械臂。

## 会议空间

打开 `/meeting.html`。说「组织三个人开会，主题是桌面伙伴的演示方案」，系统随机给 1–8 位虚拟参会者分配不同名字和职责。可以说「请小鹿写三条演示检查项」，也可以先点一位成员，再直接交代任务。实际名字以所在会议席位为准。

Agent 先给出行动步骤，必要时追问。说「让小鹿把检查项改成清单」可修改方案；点名提问或说「请大家讨论」可听取意见。每次群体讨论采样最多三位参会者，后发言者能看到前面的意见。没有清楚的交付条件时，任务显示「待补充」。

说「确认执行 小鹿」或「确认执行全部」，也可点击任务卡的「确认执行」。服务端核对方案版本；修改前的确认不能运行新版。任务完成后显示摘要、交付物、适用边界及可下载 JSON。若任务明确给了轨迹起终点数字，确认后可调用同一个机械臂计算服务，例如输入「从 [2.6,1.45,0.3] 到 [2.45,1.13,0.65] 计算机械臂轨迹」。

会议参与者是虚拟角色。其交付范围为当前对话材料的分析、方案和文稿，以及已接入的轨迹计算，不会邀请现实人员或自动执行外部软件里的任务。会议保存在当前运行的本机服务内存中，可下载成果；服务重启不保留会话。物理场景在当前浏览器中保存。
