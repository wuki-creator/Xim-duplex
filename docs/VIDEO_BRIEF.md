# Xim Duplex 演示视频

成片：约 26 秒，16:9，1280×720 / 30 fps，暗色科技感、双向声波与琥珀色机器人眼睛。主角为本平台自己的 Three.js 角色。只描述已实现的界面与设计意图，不显示未经测试的延迟或“世界第一”等结论。

1. 0–5 秒：黑暗中唤醒角色，标题 XIM / DUPLEX，字幕“持续倾听，自然回应”。
2. 5–12 秒：双向声波与两条并行轨迹，标注“输入持续开启 / 回复可被打断”；角落显示“交互概念演示”。
3. 12–19 秒：悬浮对话面板，用户说“等一下，换个说法”，旧波形停止，角色转向新消息。
4. 19–26 秒：三步反馈环“表达 → 反馈 → 迭代”，最后回到角色和“对话，由你掌控”。

制作记录：使用平台 Three.js 角色画面制作原创动画源素材，按固定时间逐帧生成，避免实时录制跳帧。随后在 ChatCut Desktop 0.9.15 建立五段镜头的时间线，添加原创电子氛围音轨、音量与淡入淡出，经原生预览核对后由 ChatCut 导出 H.264/AAC MP4。

成片已放入 `public/media/xim-demo.mp4`，前端通过对话页下方的「观看 Xim 概念演示」打开。音频不自动播放。画面字幕写明“交互概念演示”，示例对话不是性能实测。

ChatCut 工程名：`Xim Duplex — Conversation Demo`；5 个视频片段 + 1 个音轨，共 778 帧。源视频、原始角色、动画逻辑及音频保存在该工程的 `workspace/xim`，不依赖临时文件。剪辑与音频可在 ChatCut 内调整；片段内部文字保留在本仓库 `docs/video-assets/motion.js`，以视频素材导入，并未伪称为 ChatCut 原生可编辑文字层。
