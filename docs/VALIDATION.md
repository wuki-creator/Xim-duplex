# 验证记录 · 2026-11-16

## v0.6.1 本轮更新

- 14 项自动测试通过，新增打断保留原用户意图、只发送已确认播放前缀、旧播放回调失效、无 boundary 降级、手动断句和上下文传入模型两条输出路径。
- Edge 浏览器模拟播放事件：第一段完成、第二段被打断，后续请求只包含第一段；桌面/移动尺寸无脚本错误或横向溢出。此测试没有测量真实声学停播时间。
- 真实 DeepSeek API 收到“不是工作，是家里的事”及被打断前缀后，正常按新语义回应。

- 当前增加音量、设备、识别阶段和原因提示；并未据此证明 Windows 听写模型已修复。

以下为前一版本的历史记录，不代表最新真人验收通过。

## 已验证

- Node 8 项自动测试通过：JSON 空白回退、任务移除、内容过滤、过长回复、语音鉴权、异常 Origin、输入格式、旧转写丢弃、识别繁忙重试、VAD 与晋级证据门槛。
- npm 生产依赖审计：0 个已知漏洞（检查当时结果，依赖状态会变化）。
- Edge 桌面 1440 px 与移动 390 px：无横向溢出、无页面脚本错误，无任务/专注导航。
- 真实 DeepSeek API：中文短句有正常回答，未再出现原先的 INVALID_MODEL_OUTPUT。
- 本机 Windows 中文听写：使用系统语音合成的固定测试音频完成转写。预热后单次转写约 1.6 秒；这是单样本开发检查，不是 P95 或用户研究结论。测试句“今天有点累，陪我聊聊吧”被识别为“今天有点累陪我聊了吧”，仍存在转写错误。
- 浏览器测试以固定音频替代麦克风，走真实 AudioWorklet、WebSocket、VAD、本机识别及 DeepSeek 链路，产生回答；结束语音后输入关闭。它不能替代真实麦克风、扬声器回声和多人场景测试。
- ChatCut 本机五段剪辑、音轨与预览已检查；原生导出 MP4 完成。前端播放、跳转、关闭暂停已检查。

## 未验证与限制

- Whisper 的新装原生依赖被该机器 Windows 应用控制拦截，当前使用系统识别后端。未关闭或更改系统安全控制。
- 尚无真实用户独立盲评，未运行权重训练、SFT 或 DPO；策略仍为初始版本，没有自动晋级候选。
- 未对照 MOSS-Live 测量首音、误打断、情绪偏好和成本；不作最高水平或 SOTA 结论。
- 级联输出等待完整文字；附和判断、语义轮次、多人选择性注意及高质量流式 TTS 是下一阶段。
